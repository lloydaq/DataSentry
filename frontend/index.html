Dataset diagnostics for machine learning

Find data problems before they reach your model.

DataSentry profiles a CSV file on your machine and explains what it finds, with the evidence behind every finding, why it matters, and what to check next.

  • Completeness & uniqueness missing values, duplicate rows, empty columns
  • Column quality constant, redundant, identifier-like and inconsistent columns
  • Distributions numeric statistics, IQR outlier candidates, category frequencies
  • Target & leakage class balance, label conflicts, features that predict the target too well

    DataSentry never guesses the target from column names. Selecting one adds class-balance, label-conflict and leakage checks.

    Label review

    Trains a simple logistic-regression model with 5-fold stratified cross-validation and lists rows where the out-of-fold prediction disagrees with the given label. Preprocessing is fitted inside each training fold.

    Disagreement is a reason to look at a row, not proof that its label is wrong. Labels are never changed.

    Train/test overlap

    Treats the current file as the training set and checks a holdout or test file for rows that also appear in training, and for matching features with different labels.
