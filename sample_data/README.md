# Sample data

All files are **synthetic**: generated by `scripts/generate_sample_data.py` with a fixed seed. They
describe no real people or organisations. Regenerate with:

```powershell
.\.venv\Scripts\python.exe scripts\generate_sample_data.py
```

## `customer_churn.csv` (classification, target `churned`)

| Planted issue | Expected DataSentry result |
|---|---|
| `legacy_segment` is always empty | `all_missing_column` |
| `country` is always `US` | `constant_column` |
| ~6% of `age` missing; three implausible ages (142–160) | `missing_values`, `outlier_candidates` |
| `plan` spelled `basic `, `STANDARD`, `premium` in 12 rows | `inconsistent_category_variants`, `surrounding_whitespace` |
| `tenure_days` = `tenure_months` × 30 | `highly_correlated_columns` |
| 15 exact duplicate rows appended | `duplicate_rows` |
| 6 rows without a label | `missing_target_labels` |
| `cancellation_code` is only set for churned customers | `possible_target_leakage` |
| 8 labels flipped | candidates in label review (not guaranteed to be found) |
| ~3:1 class ratio | `class_imbalance` observation (not a defect) |

## `customer_churn_holdout.csv`

Same schema; 160 new rows plus 20 rows copied from `customer_churn.csv`. Use it on the
**ML checks → Train/test overlap** card with `customer_churn.csv` loaded.

## `sensor_energy.csv` (regression, target `energy_kwh`)

| Planted issue | Expected DataSentry result |
|---|---|
| `voltage_reading` has `ERR`, `n/a?`, `--` in 9 rows | `mixed_numeric_text` |
| `humidity_pct` has two `inf` values | `infinite_values` |
| `pressure_hpa` 15% missing | `missing_values` |
| `firmware` always `v2.4.1` | `constant_column` |
| `reading_id` unique integers | `possible_identifier` observation |
